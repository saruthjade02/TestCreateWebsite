# Backend Learning Resources

## Knowledge

- [Node.js SQLite](https://nodejs.org/download/release/v26.5.1/docs/api/sqlite.html)
  File-backed databases, table creation, and bound SQL statements for the local signup lesson.
- [Node.js crypto](https://nodejs.org/download/release/v26.5.1/docs/api/crypto.html)
  Asynchronous scrypt and randomBytes for salted password hashes in the local signup lesson.

- [SQLite appropriate uses](https://www.sqlite.org/whentouse.html)
  Explains when an embedded database fits and when client/server database engines are preferable.
- [PostgreSQL overview](https://www.postgresql.org/about/)
  Official overview of the PostgreSQL relational database system.
- [MDN JSON.parse](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/parse)
  Use for converting incoming JSON request text into objects in lesson 3.

- [MDN JSON.stringify](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/stringify)
  Converts JavaScript values to JSON text. Use for lesson 2 and later JSON request/response bodies.

- [Node.js HTTP documentation](https://nodejs.org/download/release/latest-v25.x/docs/api/http.html)
  Official API documentation for createServer, response headers, response.end, and server.listen. Use for the first local-server lesson.
- [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
  Use when implementing signup: password hashing and choosing appropriate algorithms.
- [MDN secure cookie configuration](https://developer.mozilla.org/en-US/docs/Web/Security/Practical_implementation_guides/Cookies)
  Use when implementing login sessions and cookie attributes.
