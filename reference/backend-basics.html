Backend: คำศัพท์พื้นฐาน

  • Frontend: โค้ดหน้าเว็บที่ทำงานในเบราว์เซอร์
  • Backend: โปรแกรมฝั่งเซิร์ฟเวอร์ที่รับคำขอและส่งคำตอบ
  • Request (req): คำขอที่ส่งเข้าเซิร์ฟเวอร์
  • Response (res): คำตอบที่ส่งกลับ
  • Port: หมายเลขช่องทางที่โปรแกรมรอรับการเชื่อมต่อ เช่น 3000
  • 127.0.0.1: ที่อยู่ที่ใช้เข้าถึงเครื่องตัวเอง
node server.ts    # เริ่มเซิร์ฟเวอร์
Ctrl+C            # หยุดเซิร์ฟเวอร์

แหล่งอ้างอิง: Node.js HTTP
