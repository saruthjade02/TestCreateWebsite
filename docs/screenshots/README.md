# ภาพหน้าจอสำหรับ README

ภาพในโฟลเดอร์นี้แสดงใน README หลัก ได้แก่ หน้าแรก แอป กราฟหุ้น รายการสินค้า รายละเอียดสินค้า เข้าสู่ระบบ และสมัครสมาชิก

หากต้องการเพิ่มภาพในภายหลัง สามารถแคปเมนูโปรไฟล์หลังเข้าสู่ระบบหรือหน้าแรกในขนาดหน้าจอมือถือ แล้วเพิ่มลิงก์ภาพใน README หลัก ใช้บัญชีทดลองและตรวจภาพว่าไม่มีข้อมูลส่วนตัวก่อนนำขึ้น GitHub
