# Mission: Build the website's account system

## Why
Learn backend development to connect the existing HTML/CSS/TypeScript website's signup and login forms to real user accounts. The user wants to understand and write the code step by step.

## Success looks like
- Run a local backend and explain how a browser receives its response.
- Send form data to a backend and validate it there.
- Create accounts with securely hashed passwords and authenticate users with sessions.

## Constraints
- Teach in Thai with small examples and explanations of individual lines.
- Build on the existing frontend; do not require migrating to React.
- Node.js is already installed. Keep the first lesson free of additional packages.

## Out of scope
- The first lesson does not implement authentication or store user data.
